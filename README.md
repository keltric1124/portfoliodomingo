# Yuriz Ronell Domingo | Portfolio

A responsive portfolio for selected product work, development capabilities, and contact information. Built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local address after the development server starts.

## Checks

```sh
npm run lint
npm run build
```

## Project content

Project descriptions and images are maintained in `src/assets/components/Project.jsx`. Add real project URLs and case-study details there when available. Do not publish placeholder links or unverified outcomes.
